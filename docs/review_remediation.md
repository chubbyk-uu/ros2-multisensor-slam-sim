# 2026-07-30 自研 SLAM 工程审查整改

本文记录工程审查意见的处理结果，用于区分已经修复的问题、仍需通过长路线
验证的行为，以及当前阶段有意不接入实时链路的实验代码。

## 已完成的高、中优先级整改

| 审查项 | 处理结果 |
| --- | --- |
| 无优化构建 | 默认构建类型设为 `RelWithDebInfo`，README 的构建命令显式传入该类型。 |
| 回环阻塞激光回调 | 回环候选匹配和 Ceres 优化改为后台任务，只读取不可变状态快照；主线程事务式合并结果。 |
| 地图重建可能饥饿 | 当前重建不再被新回环清零，只保留最新待处理快照；调度状态已抽出并有单元测试。 |
| 未捕获异常 | 节点构造、单帧扫描处理、地图发布和后台结果合并均有异常边界和明确日志。 |
| 扫描元数据缺少校验 | LaserScan、里程计、TF、投影点、位姿图输入均检查有限性和有效范围。 |
| Path 带宽与线性搬移 | 轨迹按运动量采样、2 Hz 发布、限制长度；到达上限后按批次裁剪，避免每帧搬移。 |
| 墙钟定时器 | 地图发布和分批重建使用节点时钟，遵循 `use_sim_time`。 |
| 失败回环污染位姿图 | 后台只优化图副本；只有完整验证和优化成功后才向实时图事务式提交约束。 |
| 回环仅有分数门限 | 增加累计行程、连续候选链、支撑占比和最大平移/旋转修正量约束。 |
| 回环搜索语义不一致 | 候选半径和匹配搜索窗口对齐；粗搜索与精搜索使用独立窗口和步长。 |
| 新区域拉低匹配分数 | 分数只对相关栅格范围内的点归一化，支撑点占比作为独立门限。 |
| 地图重建异常状态 | 排队版本启动失败时清空重建状态，不让异常穿透定时器或留下过期 active 快照。 |
| 回环提交后日志歧义 | 提交前拒绝与提交后 Path/地图刷新失败使用不同异常边界和日志。 |
| 热循环重复查表 | 支撑检查与似然读取合并为一次栅格采样，审查微基准降低约 29%～34%。 |
| 弱回环保护门限 | 连续候选链由 3 提高到 10，最大旋转修正由 0.50 rad 收紧到 0.25 rad。 |

## 已完成的可维护性整改

- `Point2D` 已移到纯几何头文件，基础几何库不再传递依赖
  `sensor_msgs`。
- 关键帧容器和位姿图节点下标有显式不变式检查，插入和回环合并为事务式。
- 补齐库导出、直接依赖、维护者信息，并把各包最低 CMake 版本提高到
  3.10。
- 接入 `ament_lint_auto`、Uncrustify、CMake lint、PEP 257 和可用的
  Cppcheck 检查。
- `normalizeAngle` 改为有界时间实现；里程计在激光时间戳处插值。
- 激光里程计输出提供非零位姿协方差和未知速度协方差。
- 720 束 360° LiDAR 不再重复首尾方向。
- 占据栅格由逐单元哈希改为 16×16 分块稠密存储，同时保留未知单元语义。
- 导航回归的场景超时使用仿真时钟，Nav2 激活另有墙钟看门狗。
- 两个自研 SLAM 回归工具的严重日志判据覆盖节点全部 10 条
  `ERROR`/`FATAL` 消息，失败时直接给出原因而不是只暴露症状。
- 候选链门限与关键帧间距的耦合已写入参数文档，并给出实测上限。

## 当前阶段保留的设计

- 点到线 ICP 仅作为离线算法对照，不接入实时前端。因此评审提出的
  KD-tree 和按关键帧分段法向估计是它接入实时链路之前的前置条件，
  不是当前运行节点的依赖。
- 相关匹配已经从同分辨率穷举改为粗到精搜索，默认局部候选数约从
  6798 降到 1620。局部参考子图目前随每个成功关键帧滑动，简单缓存会在
  正常路径中每帧失效；真正的增量缓存应和固定生命周期子图一起设计，
  暂不加入容易失效的缓存层。
- 地图保存的 launch 退出钩子仍会等待保存服务完成。这是为了保证
  `Ctrl+C` 后地图落盘的有意同步行为，最坏等待时间和原因已在代码中注明。
- 当前相关分数以每个候选落入栅格包围盒的点数归一化，因此候选之间的
  分母并非严格固定。直接改回整帧点数会重新惩罚进入新区域的扫描；后续
  将结合走廊和大场景回归，评估“在预测位姿处固定有效点集合”的方案。

## 验证边界

算法模块、回环处理器、地图重建队列、分块地图和容器裁剪均有纯 C++
单元测试。当前异步架构已完成 12.57 m 两圈长闭环回归：210 个关键帧、
4 次回环和 4 次完整地图重建。收紧回环保护门限后再次回归，最终误差
`0.0067 m / 0.315°`；优化地图
已成功保存为 YAML/PGM。

快速旋转已增加独立自动回归：预热后分别以 `0.30`、`0.60` 和
`1.00 rad/s` 原地旋转两圈，三档最大前端间隔均为 `0.100 s`，无拒配、
误回环或地图面积膨胀，匹配闭合误差均低于 `0.018 m / 0.51°`。后续验证
边界是退化走廊和更大场景，不再把长闭环与快速旋转列为未完成项。

单向退化走廊也已建立自动回归：25.104 m 行程中横向峰值 `0.030 m`、
航向峰值约 `0.001°`，无拒配或错误回环，地图横向范围保持 `2.95 m`。
纵向峰值 `0.855 m` 暴露了平行墙不可观测方向上的相关匹配滑动，已作为
后续退化检测的明确基线。尚未完成的是掉头返回、重复结构混淆和大场景。
