# 项目状态

最后更新：2026-09-04。

## 当前可用能力

- 2D：SLAM Toolbox 与自研相关匹配 SLAM 均可建图、保存地图并用 Nav2 导航；默认局部
  预测为轮速 + IMU EKF。
- 3D 成熟基线：RTAB-Map 可在线建图、生成二维导航投影，并以 3D 点云参与局部避障。
- 3D 自研：GICP 前端、回环后端、全局地图、二维投影、在线 Nav2、快照继续建图和
  只读 localization 均已接通。
- 自主探索：自研与 RTAB-Map 共用 Frontier 调度；自研链路支持自动快照和从 SDF
  几何采样的安全随机出生点。
- RGB-D 基础设施：前向相机模型、标准 optical frame、RGB/Depth/CameraInfo 桥接、
  可选彩色点云、独立大消息 DDS 保护、RViz 入口和数据契约回归已经接通。
- RTAB-Map RGB-D 在线基线：官方 `rgbd_sync`、外部轮速 + IMU 里程计、视觉注册、
  深度二维投影和专用 RViz 已接通；短程活动冒烟的同步频率、图节点、数据库、TF
  与栅格契约均通过。
- RGB-D 固定输入：一圈数据契约和带方向性纹理的两圈视觉回环正样本均已固化；
  RTAB-Map 两圈固定回放的七项误差、视觉回环、资源与地图判据全部通过。
- RGB-D 在线验收：默认 `640 × 480 @ 30 Hz` 现场渲染、两圈运动、视觉回环、轨迹、
  地图与资源判据全部通过；长程 CameraInfo 实测 `30.304 Hz`。
- RGB-D 交互导航：单一组合 launch 已接通 Nav2 与专用 RViz，短距离
  `NavigateToPose` 动作实测接受并成功完成；这是项目最终采用的“RGB-D 建图/定位
  + 3D LiDAR 避障”松耦合导航链路。

## 最近已验证的结果

- 自研 3D `localization` 恢复固定包 v5：`11/11` 判据通过。
- 三世界随机出生独立验证：`structured_loop_3d.sdf`、`slam_world.sdf`、
  `large_warehouse.sdf` 各 `5/5 ACCEPTED`。
- Nav2 启动期与运行期故障注入均可提前归类为 `INFRA_UNSTABLE`，不会被误记为
  地图完成。
- 2D 完全封路验收：`blocked_road_world` 中九项检查通过，规划器 `NO_VALID_PATH`、
  `30.1` 秒内停稳，真实车体净空 `0.744 m`、碰撞介入 0 次；可执行负向对照
  （`seal_offset_x:=1.5`）五项核心检查同时失败且 launch 非零退出。
- 自研 3D 导航安全验收：动态障碍 10 项检查通过（局部/全局代价地图均观测到、
  新障碍局部几何判据下净空 `0.321 m`、绕行 `1.159 m`、零碰撞；障碍横移后
  `detour_observed` 独立失败）；完全封路九项检查通过
  （`NO_VALID_PATH`、`30.9 s` 内停稳、净空 `1.629 m`）。两种场景的负向对照均按
  预期非零退出。
- 固定包上自研 3D 与 RTAB-Map 的四维对照：开回环累计各六趟，位置 RMSE 中位数
  `0.01131 m` 对 `0.03247 m`（录制里程计 `0.1596 m`），观测差距 `2.25x`–`4.43x`；
  完整进程资源复测中，自研平均 CPU 为 RTAB-Map 的 `1.33x`、末态 RSS 为其 `53.7%`。
  关闭回环首批三趟为 `13.42x`–`17.47x`，二维投影可导航面积相差不到 3%。
- RGB-D 默认档实机回归：`640 × 480 @ 30 Hz` 的三次 180 帧窗口中 RGB/Depth
  平均为 `27.253–30.298/29.460–30.298 Hz`、时间戳配对率为 `97.2%–100%`，每次
  十三项检查全部通过。全量稠密点云会把同机 RGB/Depth 平均速率降至约
  `22.984/19.862 Hz`，因此只作为显式调试接口。
- RGB-D 两圈固定回放：接受 `178` 次视觉回环，位置 RMSE `0.271 m`、末端误差
  `0.062 m`；同包输入里程计分别为 `0.642/1.263 m`，处理 P95 `82.773 ms`。
- RGB-D 在线两圈正式运行：`134` 次视觉回环，位置 RMSE `0.093 m`、末端误差
  `0.031 m`，处理 P95 `64.734 ms`，平均 CPU `31.2%`、峰值 RSS `1085.0 MiB`。

完整结果、门限和证据链接见[验收记录](acceptance.md)。

## 项目范围收口

- RTAB-Map RGB-D 负责视觉建图、定位、深度二维地图和 `map -> odom`。
- 轮速 + IMU EKF 提供连续的 `odom -> base_footprint`。
- 3D LiDAR 不进入 RTAB-Map，只供 Nav2 障碍层和碰撞监视器使用。
- 自研 3D LiDAR SLAM 保持独立，不接收 RGB-D 候选或视觉约束。
- 当前不再推进 LiDAR—视觉融合、RGB-D 补充障碍、双目或完整 LIO；后续仅维护
  已有链路、修复缺陷并保持自动回归通过。

完成阶段与明确的范围边界见[项目路线图](../plan.md)。
